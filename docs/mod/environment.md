# Environment control: time of day and weather

Debug-UI controls to change the time of day and the weather in-game, for testing rendering under different lighting. The engine handles — addresses, offsets, and the caveats — live in the pyxis-defs (`WorldTime`, `Weather`, `Atmosphere`, `LandscapeManager`, `WeatherController`, `DayCycle`); this doc is the how and the gotchas.

## Time of day

[`WorldTime::SetTimeOfDay`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/environment::WorldTime##func-SetTimeOfDay) takes hours (0–24); it wraps to 24, fires the per-hour event, and clamps against `m_PauseTimeOfDay`. It's the preferred setter over writing `m_CurrentTimeOfDay` on the `WorldTime` singleton directly, which skips the clamp and the event. The render engine copies `m_CurrentTimeOfDay` out each frame, so the change propagates to lighting on its own. `DayCycle::Apply` is the in-engine reference that drives both time and weather.

## Weather

Weather isn't a named-preset enum — it's a continuous scalar model on the live `Weather`, reached through the `LandscapeManager` singleton → its `m_Atmosphere` → `Atmosphere::GetWeather` (the `m_Weather` it hands back). The direct writers are [`Weather::SetSeverity`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/environment::Weather##func-SetSeverity) (its range, from clear to storm, is documented on [`Weather::m_Severity`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/environment::Weather##field-m_Severity)), `UpdateSeverityTarget` (smooth), and `SetWeatherTime`, plus the `m_SnowRatio` / `m_RainIntensity` scalars.

The catch is that `WeatherController` overwrites those scalars toward its own targets every frame, so a direct write won't hold. The robust, engine-sanctioned way to *pin* a weather state is to fire one of the named events the controller subscribes (in [`WeatherController::Init`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/environment::WeatherController##func-Init)) — [`EVENT_SUNNY`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/environment::WeatherController::EVENT_SUNNY), [`EVENT_RAIN`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/environment::WeatherController::EVENT_RAIN), [`EVENT_SNOW`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/environment::WeatherController::EVENT_SNOW), [`EVENT_RESTORE`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/environment::WeatherController::EVENT_RESTORE), [`EVENT_INSTANT`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/environment::WeatherController::EVENT_INSTANT), plus `cloud_base` / `cloud_height` — via the engine's event send. The mod uses the static by-name overload `NEvent::CSendEvent::SendMsg(const char*, void*)` (in pyxis-defs as `event.pyxis`; `CDialogue::Play` firing `on_play_dialogue` is the in-engine reference for the idiom), with a null payload for the payload-less weather events. The doc comment on each `EVENT_*` constant gives the severity, rain intensity, and snow ratio that event pins.

## UI

The debug UI's Tools > Environment feature (`payload/src/ui/environment.rs`) reads and writes the singletons directly, re-reading each value every frame so drift is visible. Time of day is a 0–24h hour slider calling `SetTimeOfDay`, plus a day-cycle speed multiplier ([`WorldTime::m_SpeedMultiplicator`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/environment::WorldTime##field-m_SpeedMultiplicator), 0 = frozen). Weather offers a row of event buttons — Sunny, Rain, Snow, Restore, and Instant — that fire the corresponding named events through `NEvent::CSendEvent::SendMsg` (the static by-name overload, `jc3gi::event::send_event_msg`), the sanctioned way to pin a state; below them sit a severity slider (0–4, spanning the clear-to-storm range of `Weather::m_Severity`) calling `SetSeverity`, plus direct `m_RainIntensity` and `m_SnowRatio` sliders, which the `WeatherController` pulls back toward its own target each frame unless one of the events holds the state.
