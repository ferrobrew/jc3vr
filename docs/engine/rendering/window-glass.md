# Window glass

How the game damages and draws window glass: a window's metadata, how bullets crack it, what the shader draws, and what the game lacks. The mod's use is in [breaking-glass.md](../../mod/input/breaking-glass.md).

## Glass is drawn, not simulated

Physics bodies pass through windows (which collision filter keeps them apart was not traced). A window has shapes that answer ray queries with the glass material, [`EGameMaterialId_Glass`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/physics::GameMaterialId##variant-EGameMaterialId_Glass), and a bullet's ray meeting them is the only way the game finds a window to damage. The glass is a model instance drawn with the window render block, [`RenderBlockWindow`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::render_block::RenderBlockWindow): a vehicle's windows are parts with their own model instances, the world's panes static instances in the model collections.

## The window metadata

A model instance's render info starts with a tagged metadata word, [`ModelInstance::m_MetaFlags`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::model_instance::ModelInstance##field-m_MetaFlags): the address of a [`MetaData`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::window_damage::MetaData) block, directly or through a shared record when the indirect tag bit is set (`META_INDIRECT`, `META_INDIRECT_OFFSET`). The block's first word is its kind; a window's block is a [`MetaWindow`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::window_damage::MetaWindow) (kind `MetaDataType::Window`), which holds the window's damage as a [`WindowContactPointList`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::window_damage::WindowContactPointList).

The list keeps two fixed arrays of contacts, one per [`WindowDamageKind`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::window_damage::WindowDamageKind), of which only the `Point` list is drawn. A contact is a position in the instance's own space and a strength ([`WindowContactDamage`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::window_damage::WindowContactDamage)). [`WindowContactPointList::AddDamage`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::window_damage::WindowContactPointList##func-AddDamage) adds a contact or, when one lies close enough (the merge radius scales with its strength), adds to that contact's strength, clamped to one, so repeated hits on one spot stop adding damage there; a full list grows its nearest contact. The main thread writes while the render thread reads: a new contact is written before the count is raised atomically. Metadata blocks are reference counted and destroyed from a deletion list on a later frame, so a block found through a live instance stays valid for the frame.

## How bullets crack glass

A bullet sweeps a ray from its last position to its new one on the query layer ([`PhysicsSystem::QUERY_LAYER`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/physics::PhysicsSystem)). On a glass hit, its hit handler calls [`Bullet::OnBulletHitGlass`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/equipment::weapon::Bullet##func-OnBulletHitGlass) before handling the hit object:

1. [`GetModelInstancesHit`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/physics::GetModelInstancesHit) asks the hit object for the hit shape's model instance, from the shape key and body ([`CastRayInfoBase::m_ShapeKey`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/physics::CastRayInfoBase##field-m_ShapeKey)), into a [`ModelInstanceArray`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::model_instance::ModelInstanceArray) over a stack buffer.
2. Finding none, it looks up the static panes in a centimetre box around the bullet ([`ModelCollection::GetIntersectingDecalModels`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::model_instance::ModelCollection##func-GetIntersectingDecalModels)).
3. For each instance with window metadata, it maps the bullet's position into instance space (the rigid inverse of [`ModelInstance::GetMatrix`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::model_instance::ModelInstance##func-GetMatrix)) and queues a call that adds a damage point there with the bullet's fixed strength ([`MetaWindow::AddWindowDamagePoint`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::window_damage::MetaWindow##func-AddWindowDamagePoint)).

Bullets update on worker threads, so the call is queued; the ammunition manager's render update runs the queue first, on the main thread ([`AmmunitionManagerHandleDeferredQueue`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/equipment::explosive::AmmunitionManagerHandleDeferredQueue)). The handler plays no effect or sound. The vehicle part code adds points to a part's window through the same function.

## What the shader draws

[`RenderBlockWindow::Draw`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::render_block::RenderBlockWindow##func-Draw) draws nothing while the instance's colour alpha ([`ModelInstance::m_FadeAlpha`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::model_instance::ModelInstance##field-m_FadeAlpha)) is zero. Otherwise it passes the alpha and the damage weights in the material constants, and the `Point` contacts, moved to world space, in the `WindowContactPoints` constant buffer (`NumPoints`, then each position and strength).

The `windowdamage` fragment shader loops over the contacts, projecting the pixel's offset from each onto the glass's tangent and bitangent, plus one half, to sample a crack texture (`DamagePointPropertyMap`, `DamagePointNormalMap`), so a contact's cracks span about a metre; each fourth contact mirrors the texture differently. A pixel whose crack mask, weighted by the damage weights, falls under the contact's strength (saturated) is cracked: the crack normal, a brightened colour, and an alpha of at least 0.6. The output alpha is the larger of that and the glass's own, times the material alpha. Damage therefore only makes glass more opaque: the shader has no discard or transparent state, the metadata has no broken state, and nothing in the window path hides a pane, so a window is drawn cracked over, never open.

## What a pane can be hidden with

[`ModelInstanceManager::HideModelInstance`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::model_instance::ModelInstanceManager##func-HideModelInstance) clears an instance's `VISIBLE` and `FLAG_ENABLED` bits and removes it from its culling context, which it keeps so [`ShowModelInstance`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::model_instance::ModelInstanceManager##func-ShowModelInstance) can bring it back; every render block of the model goes with it. A model's render blocks are listed per LOD by [`Model::GetRenderBlocks`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::model_instance::Model##vfunc-GetRenderBlocks) over [`Model::CountLods`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/graphics_engine::model_instance::Model##vfunc-CountLods), and a window block is told apart by its virtual table (`RenderBlockWindow::VFTABLE`).

Hiding leaves the glass's ray shapes, so rays still meet glass where the pane was.

## What a bullet does at glass

[`Bullet::HandleHit`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/equipment::weapon::Bullet##func-HandleHit) moves the bullet to the hit, cracks the pane on a glass hit, then handles it as a hit on the object the glass belongs to (for a car window, the vehicle takes the damage and impulse). The bullet passes through when a uniform random number exceeds the hit material's [`GameMaterialDesc::m_BulletCollideFactor`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/physics::GameMaterialDesc##field-m_BulletCollideFactor), and otherwise stops. A bullet that passes ([`Bullet::m_HasPenetratedOneObject`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/equipment::weapon::Bullet##field-m_HasPenetratedOneObject)) starts its next ray at the hit and ignores the whole object it passed for the rest of its flight ([`Bullet::m_RayIgnoreList`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/equipment::weapon::Bullet##field-m_RayIgnoreList)), so it can hit the occupants, objects of their own, at full damage. The collide factor is material data, one unless set; its value for glass is not in the code.
