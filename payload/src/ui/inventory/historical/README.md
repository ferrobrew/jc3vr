# Historical UI source parity

`baseline.json` freezes the 1,405 actionable lexical templates from commit `6eeb8e17e62f19f8b63fc649a6ad4be9923f97f8`. The actionable kinds are settings, commands, selections, text inputs, and pause items. Each record retains its old lexical ID, arguments, source location, and token witness. The fixture records the historical source manifest, SHA-256 source hashes, lexical scanner hash, Python port hash, and witness format version. All 64 source blobs were compared with `git show` at that commit. Rescanning reproduced all 3,058 historical lexical records. The scanner port was inspected against the Rust scanner, and four existing fixture shapes were checked in Python. No Rust execution was used to author the fixture.

`mapping.json` assigns each historical ID to a reviewed current source path, control kind, token witness, occurrence, feature owner, and section. The initial assignments come from the source-reviewed `target/gameplay-review-20261024/ui-parity/resolved-mapping.json`, not from a source file's first candidate. The four named exceptions consolidate the Controllers turn editor with the Camera editor. All other target sharing requires an explicit reviewed exception. The exporter is retained only to reproduce the initial transformation of the ignored audit evidence. Tests never invoke it or require the audit directory.

A token witness contains the primitive call, its referenced local `let` bindings, and an attached click block or setter closure where present. Whitespace, comments, and enclosing function names do not define target identity. Changing a referenced field, changing an attached command effect, deleting a control, or adding another identical current target changes the evidence and fails the gate. Paths remain explicit review boundaries. Moving a control to another file requires a reviewed mapping update; moving or renaming its enclosing function alone does not. The frozen file hashes in `tests.rs` make changes to obligations and approved owners explicit review events. The immutable baseline must not be regenerated from current sources.

The owner and section assignments record reviewed source routing. They do not execute production dispatch and do not prove that a page renders the target. The gate also does not prove effects inside called helpers, Rust name resolution or types, runtime enabled gates, callback execution, or expansion of parameterized call sites. An attached command block is checked as source evidence; its sink is not activated. Identical lexical templates retain explicit occurrence counts. The gate does not infer distinct runtime owners from identical templates.
