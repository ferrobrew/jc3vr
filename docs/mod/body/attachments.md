# Body attachment observations

The body mirror draws the weapon sockets from copied input-tick observations and the pouch props from copied render-time matrices. It never reads a weapon, a source model, or a model instance on the pose-finalization thread. The finalized skeleton, the wrist targets, the socket observations, and the render-time pouch comparison each keep their own sampling phase, so the mirror compares like with like within a phase and claims nothing across phases.

## Weapon sockets

`controllers::weapons::docks::socket_points` observes the socket weapons under its input-thread safety contract and returns a copied `docks::attachments::Sample` to the input tick. `controllers::weapons::begin::socket_candidates` selects the interaction target poses and the final hand-specific offers, returns candidates from that sample's `points()`, and publishes the same sample for the mirror. The provider receives the acting hand and the weapon occupancy from the input tick; when neither hand holds a weapon, it applies the `volumes::reserve_long_guns` restriction before deriving candidates or publishing the sample. The sample records the character identity, the timestamp, the source character transform, the socket occupancy, the loadout item and source object identities, the hand-specific usage, and the pose or the reason it is missing.

A socket's pose comes from a visible weapon grip, a remembered bone-relative grip, a native socket bone, a configured offset from a socket bone, or nothing (an unavailable socket weapon). Each socket is reached where its weapon is seen, and the native inventory placement owns the socket bones and the weapon offsets.

Object identities are diagnostic values: they neither retain an object nor authorize a grab. The loadout and grab rules decide draw, dock, and no-fit behaviour. The final selection removes only restricted hand-specific draw offers and keeps the base socket observations, the docking offers, and the no-fit offers. A missing pose does not bypass the hand restriction. An occupied socket that cannot be observed stays a no-fit observation with its occupied state.

On each pass the mirror calls the sampler the weapon handling registers (`controllers::weapons::mirror::sample_attachments`, in the body's contributions as `BodyContributions::attachment_sampler`), which reads the published sample and draws its markers with the mirror's plane and drawing helpers. The mirror rebases the copied poses through the character's current world transform, which follows character or platform movement without another bone read, but does not refresh the observation's timestamp or reconstruct the current skeleton. A foreign character, an observation past its bounded age, a future timestamp, or an invalid source or destination transform produces no sample. A visible grip stays usable when its bone orientation is unavailable; its orientation line is then neutral.

The mirror shows the hand-specific offers where present and otherwise the socket observation: amber rings for occupied sockets, cyan for empty offers, red for no-fit offers, and gray for neutral empty-socket estimates. A missing pose has no marker. The comparison shows where the interaction targets are, not where the native weapon is drawn.

## Pouch props

The grenade and C4 pouch centres use the same volume helpers as their interaction targets, and the magazine prop uses the reload provider's stocked pouch. `controllers::weapons::pouch_models::attachments::placement` converts the supplied pouch pose into character model space and applies the prop's fixed offset and rotation (`Prop::placement`). The input loop uses the resulting local transform directly and copies the observation with its input character transform. The interaction centres keep their input-tick behaviour and are not render-interpolated.

Each input observation records its kind, side, optional magazine weapon identity, borrowed source-model identity, pouch pose, model transform, and instance visibility, with an owner identity, an owner epoch, a producer-local input sequence, and a bounded age. An unoffered pouch is distinct from an offered pouch whose source model is unavailable. Identities never authorize a pointer dereference. A stand-down clears the observation, advances the epoch, and clears the retained pouch submission, and an owner change releases the old instances before accepting another owner's placements.

`pouch_models::render_frame` computes the displayed matrix from the character and local placement histories, and immediately after applying it to the owned instance copies the same value into `attachments::RenderSample`. The weapon handling's part of the mirror (`controllers::weapons::mirror::pouches_rendered`) consumes that value in the same render call, after the model-state lock is released, and submits the markers through `controllers::body::mirror::submit_pouch_render`; it neither rebuilds the model matrix nor reads native state. Each render call advances a producer-local render sequence, which the render observation records beside the input observation's identity. These are local phase identities, not engine frame numbers, and the timestamps are only an expiry check.

`controllers::weapons::mirror::PouchRenderContext` derives the plane from the character transform copied for that render call, with the same interpolation helper as the model placement, and must carry the render sample's identity. Pouch primitives use world anchors, so the comparison does not depend on an older head sample; the plane can differ from the skeleton mirror's input-rate plane during motion.

The render mirror draws a green ring and orientation line from the applied model matrix, and a cyan ring at the copied interaction centre (carried through its captured input transform) joined to the displayed model origin by a line. A hidden, missing, unapplied, or source-mismatched model has only a red interaction ring when its target exists.

`Source::BodyMirrorPouches` owns the retained render submission beside `Source::BodyMirror`, which keeps the skeleton and socket observations. Each render call clears the prior pouch submission before any early return, as do visibility and source changes, a stand-down, an unavailable owner, and owner changes, so a missing or expired observation or an invalid render transform cannot republish an old matrix. The retained slot's bounded lifetime removes the output if the render producer stops.

## Boundaries

The shared providers change attachment placement values and diagnostics only. Claims, ammunition, model ownership, native inventory writes, reload actions, and current-joint validity are unchanged, socket candidates still pass through the cockpit-frame conversion and the resolver, and the pouch models keep their instance creation, visibility, interpolation, and release paths.

The tests drive the production adapters and the production mirror renderer through the same plane: the socket points and candidates against the rendered rings across body poses, fallbacks, rebasing, owner changes, expiry, and the long-gun restriction (including that the final candidates keep the candidate-level restriction's grab behaviour and ordering), and the pouch render matrix against the applied-matrix adapter across interpolation fractions, props, sides, platform movement, and the invalid, hidden, and mismatched cases.

The copied attachment status is separate from `MirrorStatus`. Socket status belongs to the last solve pass; pouch availability and missing counts belong to the render publication.
