# The target crate of every payload module, for the layering guard's phase one.
#
# Each line is `<module path> <layer>`. A file or a `crate::` path resolves to the entry with the
# longest matching prefix, in whole segments, so a submodule or item entry overrides its parent's.
# `lib` is the crate root file, `lib.rs`; root items such as `is_shutting_down` are listed by name.
# The assignment follows docs/architecture.md, "Crate layering". When a module moves or a new
# top-level module appears, update its line here; the guard fails on any file or path it cannot
# place.
