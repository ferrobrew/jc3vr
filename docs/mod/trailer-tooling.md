# Trailer tooling

The directing tools stage footage from inside the headset: time control, actor safety, heat control, teleport bookmarks, a spawner, the clean view, take markers, and a keymap. They live in `crates/jc3vr-tooling/src/director/` and the debug UI's Director feature; recording is [capture.md](capture.md), and time of day and weather are in [debug-ui.md](debug-ui.md#environment-controls).

Everything is applied from the director's `update` at the top of the frame on the main thread, where the engine setters that assert it (the heat manager, the teleports) must be called. The UI and hotkeys only edit the `director` settings or queue requests, and the per-frame pass reconciles the game against them, so they survive the game's resets (a respawn clearing god mode, a mission reset unlocking heat). When a switch turns off, the pass restores the default once and then leaves the game's own state alone.

The time scale is written to [`SlowMotionManager_NormalGameSpeed`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/slow_motion::SlowMotionManager_NormalGameSpeed) rather than the clock's update speed, which that manager rewrites every frame, so scripted slow motion still blends against it; the pause holds the engine clock while rendering continues. God mode, unlimited ammo, and the heat lock and cap go through the game's own setters and are re-asserted every frame.

A bookmark saves the character's world matrix to `teleports.toml` in the configuration directory, and the jump uses the game world's teleports rather than a transform write, since those also reset the animation state and camera and fire the events streaming listens for: the instant one ([`GameWorld::TeleportPlayerInstant`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/game_world::GameWorld##vfunc-TeleportPlayerInstant)) within the tuning's `director.instant_teleport_range_m`, the streamed one beyond. The spawner uses the shipped spawn tables (`jc3vr_weapons::controllers::spawn`). F4 toggles the clean view ([hud.md](hud.md)). The keymap (`director.keymap`) defaults to the numeric keypad, findable by touch under a headset.
