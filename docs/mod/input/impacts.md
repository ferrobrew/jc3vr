# Impacts

What a hand or a held object meeting something does beyond the physics: the impact sound, and for a held object its strike haptics and its blow on a character. A hand body's own blows are in [physical-hands.md, "Hits"](physical-hands.md#hits). The code is `physical_hands/sounds.rs` and `physical_hands/impacts/` in `crates/jc3vr-physical/src/controllers/`, tuned in the `sounds` section of `hands.toml` and the `impacts` section of `characters.toml`; the engine side is in [melee-and-damage.md](../../engine/gameplay/melee-and-damage.md).

## Impact sounds

A hand that meets something hard enough plays the sound the game's own melee hit makes there: the player's melee impact usage ([`AttachedEffectContainer::MELEE_IMPACT_USAGE`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/equipment::attached_effects::AttachedEffectContainer)) looked up against the struck material as the game does ([melee-and-damage.md](../../engine/gameplay/melee-and-damage.md#the-impact-effect-and-sound)), with only the sound played ([`EffectAndSoundPair::PlayOneOffs`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/equipment::attached_effects::EffectAndSoundPair##func-PlayOneOffs), effect culled), since a slap should not raise dust. The sources are a palm's touch, whose cast reads the hit material ([`CastRayInfo::GetHitMaterial`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/physics::CastRayInfo##func-GetHitMaterial)); a hand body's strong contact; and a held object's strike. A contact carries no struck shape, so the last two play flesh on a character and the default material otherwise. The game's sound events take no loudness, so strength only gates whether an impact sounds, and per-hand and shared cooldowns make one slap that both the cast and the body report sound once. Weapon handling sounds (a magazine seating, a pin) are the weapons' own animation effects; glass is [breaking-glass.md](breaking-glass.md#feedback)'s.

## Held objects

While a hand holds a body, carried or joined, the body's real solver contacts drive its strike haptics, its sound, and its blow on a character; a detached door uses the same path.

The observer detours [`HavokCollisionListener::onContactImpulseEvent`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/physics::HavokCollisionListener##func-onContactImpulseEvent), records the contact, and calls the original, replacing no game table. The solver raises the event only for bodies with the contact-event flag, so the observer leases that flag on the held body, and detours [`hknpWorld::enableBodyFlags`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/physics::hknpWorld##func-enableBodyFlags) and [`disableBodyFlags`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/physics::hknpWorld##func-disableBodyFlags) so a native change during the hold updates what release restores while the leased bit stays set. Restoring the flag first checks the world, body, owner, and instance identity.

A contact's strike speed is the held body's point velocity at the strongest manifold point along the normal, sampled after the hand drive. Resting, tangential, separating, and placement contacts give nothing, nor do contacts with the player's group or between two held bodies; contacts with Rico's torso capsules are noted for the hold instead ([physical-hands.md](physical-hands.md#the-players-own-body)). Contacts are queued with each holding hand's hold generation and delivered on the game thread after the step only if both participants are still live and the hand still holds the same body under the same generation, so a release invalidates old contacts even when the hand retakes the body. Each plays `Event::HandStrike` on every holding hand and one sound.

A character struck by an intentional, closing swing of a held prop takes the mod's calibrated strike (`blows::held_strike`, calibrated as a hand's blow is), once per swing. The character's capsule turns every contact into a native hit reaction, but that does nothing visible for a hand-held prop, so deferring to it would leave nearly every blow without effect; the observer detours [`PhysicsGameObject::DoReactToHit`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/physics::PhysicsGameObject##func-DoReactToHit) and logs when the native reaction also acted, so a session shows any blow taken twice. When it did not act on the held object, the object takes [`DMG_TYPE_IMPACT`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/damage::DamageFlags##flag-DMG_TYPE_IMPACT) damage, so a crate swung into a soldier can break. Object-on-object contacts are left to the game, and nothing else is added: no second impulse, no change to materials, bullets, or filters.
