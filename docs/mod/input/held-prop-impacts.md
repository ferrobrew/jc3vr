# Held-prop impacts

Held props use real solver contact events for strike haptics and sound. The feature is enabled by default. Its switch and counters are in the physical-hands debug settings. Carried holds and jointed holds use the same observer. A detached door uses this path when it is held as a dynamic body. Door detachment and tearing are outside this feature.

The observer detours [`HavokCollisionListener::onContactImpulseEvent`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/physics::HavokCollisionListener##func-onContactImpulseEvent), records contact values, and calls the original dispatcher. It does not replace game-owned wrapper tables or retain a callback in a game object. It leases only the held body's contact-event flag. Native flag changes during a hold update the state restored on release. Lease acquisition and release change only the contact-event flag and rebuild collision caches when that flag needs to change. Intercepted native calls retain unrelated flags and the caller's cache-rebuild mode. Release, stale input, feature disable, gameplay exit, and shutdown end the lease. Restoration checks the world, body, owner, and instance identity before changing a flag.

The pre-simulation callback samples body motion after the hand drive. Feedback uses linear velocity plus angular velocity crossed with the contact's displacement from the centre of mass. It uses the real manifold point with the largest impulse and the normal directed toward the other body. Resting, tangential, separating, initial-placement, player-group, and held-to-held contacts do not produce strike feedback. Mass, speed, solver impulse, and a per-hand interval bound feedback. A shared hold pulses both hands but plays one sound.

Queued contacts carry a timestamp and a separate hold generation for each hand. Delivery requires a fresh publication, a recent contact, a matching current body identity, and the same hold generation for each receiving hand. Repeated identical fresh publications preserve a pending contact. A release or a stale publication gap invalidates that hand's old contacts, including when it reacquires the same body. Disabling controllers, pickup, physical hands, or impact feedback rejects queued feedback. A shared contact reaches only hands that still hold the body. State decisions run under the observer lock; native calls, sound, and haptics run outside it.

Native collision damage and character reactions remain authoritative. The observer does not apply a second impulse, call a second hit reaction, or send an additional damage message. It does not change materials, bullet casts, penetration rules, collision filters, or tether constraints. Material protection therefore remains the game's own behavior; a held object is not made universally bulletproof. Collision damage attribution remains native and is not relabelled as a player melee attack.

## Acceptance scenarios

The pure production-policy tests cover rotating wide props, resting and tangential contacts, separation, invalid motion, strength bounds, repeat suppression, and independent hands. Integration tests call the production publication, lease, queue, and delivery planner without installing hooks or calling the game. They cover stale contacts and publications, drop/reacquisition, shared-hold release, each disable gate, identical publication, initial native flags, native changes during a lease, mixed flag masks, cache-rebuild modes, and identity mismatch. Headset acceptance remains required for these scenarios:

- Strike a wall, a loose prop, an upright character, and a ragdolled character with a small prop and a substantial two-hand prop. Compare native health loss and reactions with the feature enabled and disabled. Check that feedback adds no second reaction or physical impulse.
- Rotate a wide prop into an obstacle while its centre moves slowly. Check that the contact end produces feedback. Rest it against the obstacle and slide it tangentially. Check that it does not buzz.
- Repeat the cases with joint grabs enabled and disabled, with either hand, and with a shared hold. Check that one contact plays one sound.
- Release, reacquire, disable the feature, change gameplay mode, teleport, destroy the prop, and unload the payload while holding it. Check that counters stop, no stale feedback arrives, and native contacts still work.
- Hold a detached door. Check generic held-body feedback without adding door tearing. Test native ballistic protection with appropriate materials and angles rather than expecting every prop to stop bullets.
- Attach C4 to a prop, then hold and move the prop. Test attachment following and detonation. Test a held tethered prop under spring load and while reeling. These combinations have no dedicated integration fix in this slice and remain unverified.
