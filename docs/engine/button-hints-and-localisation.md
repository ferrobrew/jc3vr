# Button hints and localisation

How the game resolves a localised string, and how the HUD shows its button prompts and picks their glyphs. The button-mapping table the prompts are named from is in [input.md](gameplay/input.md#the-mapping--action-table).

## Localised strings

The localisation store is the singleton `CLocator` ([`Locator`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/ui::locator::Locator)). It owns every loaded string table (`.stringlookup`) and a map of strings registered at runtime. A string table is an ADF resource holding, per language, a sorted array of key hash and offset pairs over one shared UTF-8 string blob. `ui/ui_localization.stringlookup` carries the UI's strings in eleven languages: English, French, German, Italian, Spanish, Russian, Polish, Japanese, Brazilian Portuguese, Latin American Spanish, and Arabic.

A string's key is its name hashed with `hashlittle` and a zero seed ([`HashString`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/hash::HashString)). [`GetLocalizedStringRaw`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/ui::locator::Locator##func-GetLocalizedStringRaw) takes that hash, enters the store's reader lock, binary-searches each table's block for the current language, falls back to the runtime map, and returns a null-terminated UTF-8 string owned by the table, or null; the `GetLocalizedString` wrappers call it.

The current language is [`m_CurrentLocale`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/ui::locator::Locator##field-m_CurrentLocale), a [`Locale`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/ui::locator::Locale). `CGame::SetGameLanguage` writes it from a two-letter code (the platform's unless one is given), falling back to English for an unknown code, and tells the UI manager to switch language.

Every `buttonhint_*` key the mapping table names resolves in all eleven languages, as do `buttonhint_hold` and `buttonhint_release` (the "HOLD" and "RELEASE" prefixes) and the controls screen's tab names, `gui_settings_controller_mapping_*` ("ON FOOT", "CAR", ...).

## The button-mapping table names the prompts

Each [`MappingInfo`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/input::button_mapping::MappingInfo) carries the hash of a `buttonhint_*` key as its description. The controls screen (`CPauseUI::LoadControllerMapping`) names each row by resolving that key, so the controls screen, the HUD's prompts, and the table are one source. Several mappings share a key (the reload, holster, and fire keys recur per vehicle class), and some differ from their action's name (the melee mapping's key is `buttonhint_hammer`; the car's turn uses the helicopter's `buttonhint_heli_turn_*` keys).

## How the HUD shows its hints

1. Sources. `CPlayerActionObserver` raises the context hints, one predicate pair per hint (release the tethers, reel in, hang jump, detonate, the gunner seat, the handbrake, look back, the parachute, the sniper zoom, holster, and the rest), and the systemic hints, tutorial-like nudges whose show and hide times it saves. Graph scripts raise mission hints through the `ButtonHint` and `SystemicButtonHint` script nodes. All of them end in `CHUDUI::AddButtonHint` and `RemoveButtonHint`.
2. The queue. `CHUDUI` keeps a lock-guarded vector of `SButtonHint` ([`HUDUI::m_ButtonHints`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/ui::hud_ui::HUDUI##field-m_ButtonHints), under [`m_ButtonHintsLock`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/ui::hud_ui::HUDUI##field-m_ButtonHintsLock)): the request ([`ButtonHintRequest`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/ui::hud_ui::ButtonHintRequest): its type, normal, Y-use, or big; the whole mapping, actions, interaction, and description key; the lifetime), the two key ids, the time left, and an id. [`AddButtonHint`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/ui::hud_ui::HUDUI##func-AddButtonHint) appends one and returns its id.
3. The push. [`HUDUI::UpdateButtonHints`](https://ferrobrew.github.io/pyxis/#/JustCause3_Steam_20206564/item/ui::hud_ui::HUDUI##func-UpdateButtonHints), called from the HUD's update, ages the timed hints and, when the queue changed, builds three arrays for the movie (normal, at most three of them; Y-use; big) of id, two key strings, interaction, and description. The description is `GetLocalizedStringRaw` of the mapping's key. Each key string is `CUIBase::SetKeyString`'s `{hash}` of the action's input name: a placeholder naming the action, not a button.
4. The movie. `hud.gfx` lays the normal hints out in `MCI_safe_area_bottom_right.MCI_sys_button_hints_stage` (three hint clips) and the big hint in `MCI_safe_area_center.MCI_button_hints_stage`. Each hint's text is the hold or release prefix, the placeholder, and the description. The movie writes its hint clips' visibility, not the stages'; the cinematic code re-shows the centre stage after a cinematic. These paths are read from the decompiled movie, unconfirmed against the live display tree.

## How a prompt picks its glyph

The glyphs are Scaleform image substitutions in text fields, not a font. A movie registers its text fields with `uibase.RegisterButtonMappingTextFields`. Native `CUIBase::UpdateInputActionMap` fills the movie's public `m_ButtonMapping` array with one `{subString: "{hash}", image: <class name>}` entry per action the button-mapping table offers the UI, but only while the UI manager considers the gamepad the active device. The image name comes from the action's bound gamepad key through `CUIBase::GetSteeringActionImage` (`button_a`, `button_rt`, `button_lsup`, ...). The shared library turns each entry into an image substitution, so every placeholder in the registered fields is drawn as a bitmap from `shared_lib.gfx` (plain, Xbox, and PS4 sets). The mapping is by action, so a prompt shows the glyph of the gamepad button the action is bound to, whatever input actually drives it.

The same mechanism draws the use-item and weapon-pickup prompt (whose localised string is the bare placeholder in every language), the skip-cutscene prompt, the HUD notifications, and the pause menu's hint bars.
